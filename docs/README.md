# AgentVerse Documentation

## Research Agent

The Research Agent is responsible for analyzing initial project requirements and user stories. It breaks down user stories, identifies key features, spots potential ambiguities, and outlines high-level technical considerations to generate structured tasks for the development lifecycle.

During the requirement analysis phase, the Research Agent ingests stakeholder inputs, extracts functional and non‑functional requirements, and produces a clear, prioritized list of tasks. It collaborates with the Manager Agent to assign these tasks to appropriate downstream agents, ensuring that the development pipeline starts with well‑defined objectives.
